# Автоматизация тестов для Yougile

## Описание
Проект по автоматизации UI и API тестов для сервиса [Yougile](https://yougile.com).

🔗 Ссылка на финальную работу по ручному тестированию: [вставьте ссылку]

## Технологии
- Python 3.10+
- Selenium (UI)
- Requests (API)
- Pytest
- Allure
- PageObject

## Структура
/tests/ - UI и API тесты
/pages/ - PageObject модели
/api/ - API клиент
/config/ - Настройки и тестовые данные
conftest.py - Фикстуры
pytest.ini - Маркеры
requirements.txt
README.md
